position: relative vs position: absolute

🔹 position: relative

Phần tử giữ nguyên vị trí ban đầu trong dòng chảy tài liệu (document flow). Các thuộc tính top, right, bottom, left dịch chuyển nó tương quan với vị trí gốc mà không làm ảnh hưởng đến vị trí các phần tử xung quanh.

🔹 position: absolute

Phần tử bị tách hoàn toàn khỏi dòng chảy tài liệu. Vị trí của nó được tính dựa trên phần tử cha gần nhất có position khác static (thường là cha có position: relative).

🔹 Ví dụ Layout Responsive

Tạo một Card sản phẩm (Card relative) chứa một Badge nhãn "Giảm giá 20%" ở góc trên bên phải (Badge absolute). Khi kích thước màn hình co giãn, Badge vẫn dính chặt góc trên bên phải của Card.

🔹 Ảnh hưởng khi Deploy / Hosting

CSS chỉ xử lý phía client, không bị ảnh hưởng trực tiếp bởi hạ tầng server hosting. Tuy nhiên, việc dùng sai absolute (ví dụ cố định pixel top: 100px; left: 500px) sẽ khiến giao diện vỡ trên di động khi deploy ra môi trường thực tế.

Cần kết hợp Media Queries (@media) hoặc Flexbox / Grid để đảm bảo responsive.

Quy trình Đăng ký Domain, Cấu hình Hosting & DNS

🔹 Quy trình
  1. Đăng ký Domain: Mua tên miền qua Nhà cung cấp (Tên miền Việt Nam, PA Vietnam, GoDaddy, Cloudflare…).
  2. Đăng ký / Khởi tạo Hosting: Hosting truyền thống (cPanel / DirectAdmin) hoặc Serverless Static Hosting (GitHub Pages, Netlify, Vercel).
  3. Cấu hình DNS: Trỏ bản ghi A Record đến IP Server hoặc CNAME Record đến domain hosting của Netlify / GitHub Pages.
🔹 Vai trò của DNS

Hệ thống phân giải tên miền (Domain Name System) đóng vai trò như “danh bạ Internet”, dịch tên miền dễ nhớ (ví dụ: mysite.com) thành địa chỉ IP máy chủ (192.0.2.1).

🔹 2 Công cụ Free Deploy Static Web
  • GitHub Pages: Đẩy code lên GitHub repository, bật Pages trong Settings.
  • Netlify / Vercel: Kết nối trực tiếp với GitHub repo để tự động deploy mỗi khi push code (CI/CD).
🔹 Rủi ro bảo mật khi cấu hình sai
  • Thiếu SSL/TLS (chưa có HTTPS): Dữ liệu gửi đi dạng plain-text dễ bị đánh cắp (Man-in-the-Middle attack).
  • Sai bản ghi DNS hoặc lộ IP gốc: Dễ bị tấn công DDoS, DNS Hijacking hoặc giả mạo tên miền.
Câu 3 • 10 điểm

So sánh let, const, var – Hoisting & Debugging

🔹 So sánh nhanh

var

  • Function Scope
  • Có Hoisting (undefined)
  • Cho phép khai báo lại
  • Cho phép gán lại

let

  • Block Scope {}
  • Hoisting + TDZ
  • Không khai báo lại
  • Cho phép gán lại

const

  • Block Scope {}
  • Hoisting + TDZ
  • Không khai báo lại
  • Không gán lại (primitive)
🔹 Ví dụ lỗi thường gặp

Lỗi do dùng var trong vòng lặp bất đồng bộ:

for (var i = 0; i < 3; i++) { setTimeout(() => console.log(i), 1000); // In ra: 3, 3, 3 (i chia sẻ chung function scope) }

Sửa lỗi bằng let:

for (let i = 0; i < 3; i++) { setTimeout(() => console.log(i), 1000); // In ra: 0, 1, 2 (i có block scope riêng từng lần lặp) }
Temporal Dead Zone (TDZ): Với let và const, nếu truy cập biến trước dòng khai báo sẽ gây ReferenceError.

Event Delegation trong JavaScript

🔹 Khái niệm

Event Delegation (Ủy quyền sự kiện) là kỹ thuật lợi dụng cơ chế Event Bubbling (sự kiện nổi bọt từ phần tử con lên phần tử cha) để gắn chỉ 1 Event Listener vào phần tử cha thay vì gắn nhiều listener vào từng phần tử con.

🔹 Ví dụ ứng dụng cho Dynamic List
document.getElementById('myList') .addEventListener('click', function(e) { if (e.target && e.target.nodeName === 'LI') { console.log('Bạn đã click vào item:', e.target.textContent); } });
